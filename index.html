lincstation_leds packages

Prebuilt .deb, .rpm, and .apk packages for jchonig/lincstation_leds, a daemon that drives the Lincstation N2's disk/network activity LEDs. Each package installs a dedicated lincstation-leds system user and a systemd unit (deb/rpm) or OpenRC service (apk) that starts automatically.

Debian / Ubuntu (APT)

curl -fsSL https://jchonig.github.io/lincstation_leds/apt/lincstation-leds.gpg -o /usr/share/keyrings/lincstation-leds.gpg
echo "deb [signed-by=/usr/share/keyrings/lincstation-leds.gpg] https://jchonig.github.io/lincstation_leds/apt stable main"     | sudo tee /etc/apt/sources.list.d/lincstation-leds.list
sudo apt update
sudo apt install lincstation-leds

The key is also published ASCII-armored at https://jchonig.github.io/lincstation_leds/apt/lincstation-leds.asc for tools (Puppet's apt::key, Ansible, Chef, etc.) that infer key format from the file extension rather than always wanting the binary .gpg form.

Fedora / RHEL / Rocky / Alma (DNF/YUM)

sudo tee /etc/yum.repos.d/lincstation-leds.repo <<REPO
[lincstation-leds]
name=lincstation_leds
baseurl=https://jchonig.github.io/lincstation_leds/yum/
enabled=1
gpgcheck=1
gpgkey=https://jchonig.github.io/lincstation_leds/yum/RPM-GPG-KEY-lincstation_leds
REPO
sudo dnf install lincstation-leds

Alpine (APK)

wget -O /etc/apk/keys/lincstation_leds.rsa.pub https://jchonig.github.io/lincstation_leds/apk/lincstation_leds.rsa.pub
echo "https://jchonig.github.io/lincstation_leds/apk" | sudo tee -a /etc/apk/repositories
sudo apk update
sudo apk add lincstation-leds
